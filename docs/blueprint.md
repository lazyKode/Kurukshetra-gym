# **App Name**: AccessKey

## Core Features:

- Login Form: Simple login form with fields for username and password.
- Error Handling: Basic error message display for invalid login attempts.
- Loading state indicator: A loading state is shown when a request is being sent to avoid resubmissions

## Style Guidelines:

- Primary color: Neutral grays for a professional look.
- Accent: Blue (#3498db) for primary buttons and interactive elements.
- Clean, centered layout with a focus on usability.
- Simple, clear icons for form elements.
- Subtle transitions and feedback animations for a polished feel.
